LAFVIN ESP32-S3 4.2inch RLCD Development Board
============================================================

Welcome to the LAFVIN ESP32-S3 4.2inch RLCD Development Board tutorial.
This guide covers three ways to use the board: Arduino, ESP-IDF, and Xiaozhi AI.

Choose an entry point based on your goal:

* **Learn programming with Arduino**: start with :ref:`arduino-tutorial`
  and work through examples covering the display, networking, sensors, storage, and audio.
* **Develop applications with ESP-IDF**: start with :ref:`esp-idf-tutorial`
  to learn how to use the peripherals and combine them into applications.
* **Try Xiaozhi AI voice interaction**: start with :ref:`xiaozhi-tutorial`.
  Flash the firmware, connect to Wi-Fi, and activate the device to begin.

Instructions for installing development tools, downloading the example code,
and flashing firmware online are in the appendices.
Each section links to the relevant instructions when needed.
